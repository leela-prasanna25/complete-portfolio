# Complete Portfolio

A modern and responsive personal portfolio built using React to showcase my projects, skills, education, internship experience, and contact details. Designed with a clean UI and focused on performance, accessibility, and user experience.

## 🚀 Features
- Responsive and modern UI
- Projects showcase with tech stack
- Skills categorized by domain
- Education and internship details
- Contact section with social links
- Resume download option

## 🛠️ Built With
- React
- JavaScript
- HTML5
- CSS3
- React Icons

## 📌 Purpose
This portfolio is designed to present my technical skills, projects, and professional journey in a clean and structured manner for recruiters and collaborators.
